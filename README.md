# Bright Path Grade 2 — Updated learning dashboard

- Daily practice: 20 questions, Monday through Friday.
- Each question displays its lesson topic.
- Friday weekly exam: 30 questions with a 30-minute countdown.
- Automatic submission when time expires.
- Parent Dashboard now includes a MAP-style skill map grouped by subject.
- Each practiced skill shows accuracy, correct/attempted count, and a learning indicator:
  - Strength: 80% or higher, with at least 3 attempts.
  - On track: 60–79%, with at least 3 attempts.
  - Needs support: below 60%, with at least 3 attempts.
  - Building evidence: fewer than 3 attempts.
- The map is an internal learning snapshot, not an official NWEA MAP score or percentile.
